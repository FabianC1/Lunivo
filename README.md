# 🌿 Lunivo

Lunivo is a **Life Event Financial Planning platform** that helps people understand what they can realistically afford before committing to major life events such as weddings, holidays, and other significant milestones.

Instead of tracking past spending, Lunivo focuses on **future financial clarity**:

> “Can I afford this, and how do I get there?”

---

# 💍 Core Focus

The primary use case is **wedding planning**, with additional support for:

- Holidays and travel planning  
- Home and lifestyle events  
- Education and vehicle planning  
- Emergency fund planning  

Each event is treated as a structured financial goal with timelines, budgets, and affordability forecasting.

---

# 🧠 Key Features

## 📊 Event-Based Planning

Users create “events” such as weddings or holidays and build structured financial plans around them.

Each event includes:
- Target date
- Budget planning
- Savings tracking
- Cost breakdowns
- Milestones and timelines

---

## 💰 Affordability Engine

Lunivo calculates whether an event is financially achievable based on:
- target cost
- current savings
- time remaining

It then estimates:
- required monthly savings
- affordability status
- financial feasibility over time

---

## 🔁 Scenario Planning

Users can explore different versions of the same event to understand trade-offs, such as:
- smaller vs larger weddings
- different budget tiers
- adjusted timelines

This helps users compare financial outcomes before making decisions.

---

## 📅 Milestone Planning

Events can include structured milestones such as deposits and payment deadlines, helping users stay on track over time.

---

## 📈 Visual Insights

Each event includes visual breakdowns of:
- cost distribution
- savings progress
- budget vs target comparison
- financial trajectory over time

---

# 🎯 Product Philosophy

Lunivo is built around a simple idea:

> Most people don’t fail financially — they just commit without clarity.

The goal is to help users make informed decisions **before** they spend money, not after.

---

# 💡 What Makes It Different

Unlike traditional budgeting tools, Lunivo:

- focuses on future goals instead of past transactions  
- models real-world financial outcomes  
- treats life events as structured financial plans  
- helps users compare decisions before committing
